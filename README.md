# Snowman GIF Maker

A short Python script that turns two photos into an animated GIF using the `imageio` library. Built following the Codédex "Create a GIF with Python" project.

![Snowman GIF](snowman.gif)

## How to run
1. Install imageio: `pip install imageio`
2. Put the images in the same folder as `create_gif.py`
3. Run: `python create_gif.py`
